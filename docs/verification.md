# Проверки миграции

Проверено 18 ноября 2026 года в исходном checkout на NixOS 26.05. Работающая сессия Niri не перезапускалась и пользовательский установщик к ней не применялся.

| Проверка | Результат |
| --- | --- |
| `niri validate -c yozekos/config/niri/config.kdl` | Успешно; переносимый KDL принят установленной версией Niri. |
| `python3 -m unittest discover -s tests -v` | 9 из 9 тестов прошли: патчи Niri, привязки, курсор, запись области и частота кадров. |
| Синтаксис установщика, bash-скриптов и модуля NixOS | `py_compile`, `bash -n`, `nix-instantiate --parse` прошли. |
| Оценка модуля NixOS | `programs.yozekos.enable = true` и `sddm.enable = false` вычисляются на установленном nixpkgs 26.05. |
| Установщик во временном HOME | Проверены `--dry-run`, установка с резервной копией, повторный запуск с нулём изменений, план удаления, удаление и восстановление прежнего Niri-файла. |
| QML-ресурсы | 198 QML-файлов; все статические пути `Qt.resolvedUrl(...)` существуют; символические ссылки `Fonts.qml` не повреждены. Основной `rice-desktop` уже работает из этого checkout в текущем сеансе. |
| Локальные ссылки README | Проверены на существование файлов в репозитории. |
| Безопасность | Новые конфиги и текст проверены на абсолютные личные пути и типовые секреты; отладочные снимки с рабочими окнами исключены из публикуемой версии. |

Отдельный вход в новую сессию и установка на другом компьютере не проводились: это потребовало бы менять действующий пользовательский профиль или системную конфигурацию. Тема SDDM является необязательной и не проходила повторный тест после документационной миграции. Анимация экрана не записывалась, чтобы не захватить содержимое текущих окон.
