# Установка на NixOS

## Требования

Проверенная база — NixOS 26.05, Niri 26.04, Quickshell 0.3.x, Qt 6 и рабочий сеанс Wayland. Необходимы Python 3, systemd user и Fontconfig. Для полной работы нужны `awww`, `wpctl` (PipeWire), `playerctl`, `brightnessctl`, `nmcli` (NetworkManager), `bluetoothctl` (BlueZ), `grim`, `wl-copy`, `satty`, `swaylock`, `kitty`. Запись экрана использует `wf-recorder` и `ffmpeg`. Не все возможности нужны каждому компьютеру: отсутствие сети Bluetooth или подсветки не мешает панели запускаться.

## Пакеты NixOS

Клонируйте проект и подключите модуль в собственном файле конфигурации NixOS. Пусть `путь-к-репозиторию` — абсолютный путь к вашему checkout; в Nix-пути не используется `~`.

```nix
{ ... }: {
  imports = [ /путь-к-репозиторию/YozekOS/nix/module.nix ];
  programs.yozekos.enable = true;
}
```

Модуль добавляет пакеты, шрифты Pixeloid/Cozette, Symbols Nerd Font и курсоры. Он не выбирает сеанс входа, не удаляет поколения NixOS и не переключает систему сам. Необязательную тему SDDM можно включить через `programs.yozekos.sddm.enable = true;` после проверки её на своей машине. Если пакеты уже объявлены через Home Manager, можно оставить модуль выключенным и подключить эквиваленты из `nix/module.nix` в `home.packages`; пользовательский установщик распознаёт наличие Home Manager и не правит его файлы.

После ручной проверки своей NixOS-конфигурации выполните привычную для вашей системы сборку и переключение. Проект не запускает эти команды за вас. Если Niri ещё не включён, модуль устанавливает `programs.niri.enable` по умолчанию; выберите Niri в менеджере входа.

## Пользовательские файлы

```bash
git clone https://github.com/Yozekkk/YozekOS.git
cd YozekOS
./install.sh --dry-run
./install.sh
```

При конфликте установщик покажет пути и запросит согласие. В неинтерактивной среде используйте `./install.sh --yes` только после просмотра `--dry-run`. Резервные копии остаются в `~/.local/state/yozekos/installer/backups/`. Файлы проекта подключаются символическими ссылками; checkout не следует удалять после установки. Существующие пользовательские значения в `~/.config/yozekos/*.json` сохраняются. Конфигурация Niri разворачивается из `yozekos/config/niri/config.kdl`; специфичные для двух мониторов координаты в шаблон не включены. Личные правила добавляйте после установки.

Скрипт не скачивает коллекции обоев автоматически. Встроенные обои находятся в `yozekos/sddm/theme/walls`; установщик регистрирует их в галерее и использует `wide.jpg` при первом запуске, если пользователь ещё не выбрал фон. Необязательные большие коллекции можно загрузить отдельно: `python3 scripts/install-wallpapers.py install --packs Pixel` (проверьте условия распространения у источника).

## Первый запуск

Войдите в Niri, затем выполните:

```bash
systemctl --user daemon-reload
systemctl --user start yozekos-shell.service
yozekos doctor
```

При следующем входе Niri запускает сервис через `spawn-at-startup`. Перезапуск панели: `yozekos restart`. Текущая графическая сессия во время установки не закрывается.

## Повторная установка и удаление

`./install.sh --dry-run` должен показать ноль изменений после успешной установки. При обновлении checkout выполните `git pull --ff-only`, затем снова `./install.sh --dry-run` и `./install.sh`. Команда `./install.sh --uninstall --dry-run` показывает план удаления, а `./install.sh --uninstall` удаляет только файлы с содержимым, установленным этим установщиком, и восстанавливает прежние копии. Изменённые пользователем файлы пропускаются. Прежде чем удалять checkout, остановите сервисы `systemctl --user stop yozekos-shell.service yozekos-wallpaper.service` и выполните удаление.
