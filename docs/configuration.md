# Настройка YozekOS

Откройте `yozekos settings` или нажмите **Super+U**. Программа записывает пользовательские параметры в `~/.config/yozekos/`. Папка `~/.config/rice` — совместимая ссылка для заимствованных скриптов; не создавайте в ней отдельную копию настроек.

| Что изменить | Где искать |
| --- | --- |
| Панель, значок «Пуск», кнопки окон, Dynamic Island | Настройки → Bar; файл `bar.json` |
| Темы и цвета | Настройки → Appearance; `theme.json`, `palette.json` |
| Шрифты | Настройки → Fonts; `fonts.json`; лицензированные файлы в `fonts/pixel/` |
| Виджеты рабочего стола | Настройки → Desktop; `desktop.json` |
| Обои и переходы | Настройки → Wallpaper; `wallpapers.json`; команды `rice-walls` и `rice-wallpaper` |
| Эффекты, прозрачность, анимации | Настройки → Motion; `effects.json`, `settings-app.json` |
| Уведомления и центр управления | Настройки → Notifications; `notify.json`, `cc.json` |
| Курсор | Настройки → Cursor; `cursor.json` |
| Правила окон, клавиши, мониторы | Настройки → Niri или `~/.config/niri/config.kdl` |

Исходные значения поставки находятся в `yozekos/defaults/`; установщик копирует их только при отсутствии личного файла. Актуальный профиль панели использует нижнее положение, значок YozekOS, отдельные кнопки окон и выключенный Dynamic Island. Его можно включить в настройках и перезапустить оболочку командой `yozekos restart`. Изменяемая картинка «Пуск» задаётся в том же разделе панели.

Новые обои можно поместить в `~/Pictures/YozekOS/Wallpapers/Custom` и добавить папку через галерею. Встроенные изображения поставляются с темой SDDM. Большие сторонние коллекции загружаются отдельно через `scripts/install-wallpapers.py`; личные обои в репозиторий не попадают.

После ручного изменения Niri выполните `niri validate -c ~/.config/niri/config.kdl`. Настройки Niri сохраняют резервную копию и проверяют KDL до применения. Для нового монитора сначала посмотрите имена через `niri msg outputs`; заводские `HDMI-A-2` и `eDP-1` намеренно удалены из переносимого файла.

Шрифты Quickshell применяются сразу; GTK и Qt-приложения могут потребовать перезапуска. Терминал по умолчанию — Kitty. Другой терминал или файловый менеджер выбирается в настройках; привязки Super+Return и Super+E вызывают соответствующие обёртки.
